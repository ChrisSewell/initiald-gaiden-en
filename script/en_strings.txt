#   ^text    center the text in the original field width
#   text     left-align and pad with spaces to the original width
#   KEEP     leave the original bytes alone (already English, or not text)
# Budget = original length in bytes, minus the <end> byte. English is one
# byte per character.
#   I*  inline strings (printed by call $0CE0). Too long = needs relocating
#       (a code patch); the merge tool reports how many extra bytes.
#   T*  fixed-size table records. Must fit.
#   G000 name-entry grid. Must be exactly the original size.
# 「 」 stay drawable: lowercase goes in kana slots 0xA6 and up, so the
# punctuation tiles at 0xA1-0xA5 (。「」、・) are kept.
