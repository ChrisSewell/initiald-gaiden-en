# English for the bank 4 window tilemaps (table at 0x10000, header 08 W-1 H-1).
# These store tile numbers, so each row has a fixed width.
#   Wnn.r = text    write text into the box interior of row r (columns 1..W-2),
#                   padded with spaces. Row 0 is the top border.
#   Wnn.r := text   replace the whole row (exactly W characters).
#                   ┌─┐│└┘ draw the box border, ~ keeps the original tile.
# The build fails if any kana or dakuten tile is left in a translated window.
# Yes/No and Receive/Send stay in the original columns, where the cursor goes.
